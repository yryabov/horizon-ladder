# GitHub release manifest — v1 (working draft)

Repo (proposed): `horizon-ladder` — *A ladder of conclusions on the history of
dark energy: horizon-parametrized models vs Planck + DESI DR2 + Pantheon+.*
Companion code release for the v3.x paper. One-line pitch for the README:
every number in every table of the paper is produced by one script in this
repo, each self-validating against the official Planck chi^2 anchor before it
will run.

## Proposed layout

```
horizon-ladder/
  README.md                  <- quickstart, data setup, reproduction map (below)
  LICENSE                    <- MIT suggested
  requirements.txt           <- numpy scipy pandas camb
  battery/                   <- the six models, three batteries
  controls/                  <- no-DE, HDE eternal screen
  patchers/                  <- lya4 / sn-leg / sn-cov upgrades
  uncertainty/               <- Fisher + profile likelihood
  nulltests/                 <- CMB seam templates, SN anisotropy
  aux/                       <- pulls, low-ell forecast, frozen-cost probes
  results/                   <- the *_v1.json verdicts quoted in the paper
```

## Data the user must supply (not redistributed)
1. Planck 2018 `plik_lite` native files (via cobaya install of
   `planck_2018_highl_plik.TTTEEE_lite_native`); scripts locate them by
   filename search under `PACKAGES_PATH` and REFUSE to run unless the official
   point reproduces chi2 = 206.37 (TT anchor).
2. DESI DR2 BAO numbers: embedded in-script (Table III of 2503.14738 +
   Results-IV joint Lya row of 2607.27410).
3. Pantheon+SH0ES: `Pantheon+SH0ES.dat` + `Pantheon+SH0ES_STAT+SYS.cov`
   (github.com/PantheonPlusSH0ES/DataRelease).
4. DES-SN5YR (Dovekie): `DES-Dovekie_Metadata.csv` (github.com/des-science/DES-SN5YR).
5. Planck Commander map `COM_CMB_IQU-commander_1024_R2.02_full.fits` (PLA) —
   null tests only.
6. For the CMB data figure (`fig_cmb_v1.py`): the released `plik_lite`
   bandpower/covariance files, e.g. `GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1
   https://github.com/heatherprince/planck-lite-py` (directory
   `data/planck2018_plik_lite/`).

## Reproduction order (README core)
1. baseline battery (6 runs) -> Table 1
2. `patch_lya_row.py` -> lya4 runs (6) -> Table 2
3. `patch_sn_leg.py` (probe) + `patch_sn_cov.py` -> sn4 runs (6) + `noDE` -> Table 3
4. `fisher_sn4_v1.py all` + profile scripts -> uncertainties
5. null tests (independent of 1-4)
